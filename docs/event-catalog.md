# Каталог DOM-событий

Расширение принимает регистрации 37 типов DOM-событий. Для каждого типа локально хранится русское описание назначения; оно видно в карточке и участвует в поиске. Сборщик фиксирует метаданные регистрации. Значения полей, clipboard, event payload и код callback не собираются; срабатывания событий не отслеживаются.

## Поддерживаемые имена

| Группа                 | Типы                                                                                                                         |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Мышь                   | `click`, `mousedown`, `mouseup`, `mousemove`, `mouseenter`, `mouseleave`, `mouseover`, `mouseout`, `dblclick`, `contextmenu` |
| Указатель              | `pointerdown`, `pointerup`, `pointermove`, `pointercancel`, `pointerenter`, `pointerleave`, `pointerover`, `pointerout`      |
| Клавиатура             | `keydown`, `keyup`                                                                                                           |
| Фокус                  | `focus`, `blur`, `focusin`, `focusout`                                                                                       |
| Редактирование и формы | `beforeinput`, `input`, `change`, `submit`, `reset`, `invalid`                                                               |
| Clipboard              | `copy`, `cut`, `paste`                                                                                                       |
| Прокрутка и загрузка   | `wheel`, `scroll`, `load`, `error`                                                                                           |

Имена в `addEventListener` чувствительны к регистру. Принимаем `pointerdown`; `POINTERDOWN`, произвольные custom events и типы за пределами таблицы пропускаем. Для HTML-атрибутов обработчиков убирается префикс `on`: например, `onpointerdown` соответствует `pointerdown`.

Расширение каталога действует после загрузки новой сборки и перезагрузки страницы с выданным доступом. Высокая частота `mousemove` или `scroll` не создаёт поток записей: учитываем регистрацию обработчика и известные изменения его жизненного цикла.

## Границы покрытия

Наличие имени в каталоге задаёт допустимый тип регистрации. Доступность соответствующего Web API и поведение события определяет браузер. Каталог охватывает перечисленные группы; полного покрытия всех DOM-событий и Web API нет.

Hook `addEventListener` работает best effort: ранние регистрации могут отсутствовать. Inline-атрибуты и свойства `on...` дают сведения о поверхности с причиной `SURFACE_UNVERIFIED`. Перехват всех property setters не гарантируется. Обнаруженный атрибут сам по себе не подтверждает, что браузер создал исполняемый обработчик.

Разрешения сайта, доступность iframe и Shadow DOM, лимиты записей и восстановление после навигации сохраняют ограничения, описанные в [сборке и проверках](technical-prototype.md). Счётчики панели относятся к полученным записям, включая `removed`; они не гарантируют число активных обработчиков на странице.

## Единый источник для сборщика

`src/shared/event-catalog/catalog.ts` экспортирует неизменяемые `EVENT_CATALOG` и `SUPPORTED_EVENT_TYPES`, тип `SupportedEventType` и проверку `isSupportedEventType`. Bridge, inline/property surfaces и background используют этот модуль, поэтому список разрешённых имён не дублируется между ними.

`describeEvent` возвращает описание из каталога. Для неизвестных имён возвращается строка «Назначение этого типа события пока не описано в локальном справочнике». Ключи прототипа объекта, например `__proto__` и `toString`, тоже получают эту строку и не считаются поддерживаемыми типами. В production background неизвестная регистрация отбрасывается до сохранения.
