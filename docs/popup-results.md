# Панель результатов

После выдачи доступа и перезагрузки страницы popup показывает полученные записи по типам событий. Каждая карточка сохраняет свой frame и document: обработчики из разных контекстов не сливаются.

Все 37 типов из [локального каталога](event-catalog.md) имеют русское описание назначения события. Описание помогает понять тип регистрации; поведение callback расширение не анализирует.

## Поиск

В поле «Поиск по метаданным» вводим тип события, путь цели или другие известные метаданные. Например, `click button` оставляет записи, в метаданных которых встречаются обе подстроки. Регистр и пробелы по краям не влияют на результат; все слова должны встречаться в одной записи.

Поиск проверяет `eventType`, описание события, `source.path`, `source.target`, `source.sourceKind`, `frameId`, `documentId`, `contextKind` и `lifecycle`. Например, `removed` находит записи с удалённым обработчиком. Расположение скрипта, параметры, коды ограничений и произвольные дополнительные поля в поиск не входят.

Кнопка «Сбросить поиск» очищает запрос и возвращает фокус в поле. Поиск выполняется локально; запрос не сохраняется и не попадает в логи.

## Группы и счётчики

Группы упорядочены по `eventType`; внутри сохраняется порядок полученных записей. Счётчик «Показано записей» сравнивает число совпадений с размером текущего снимка. Число рядом с типом события относится к отфильтрованной группе.

Считаем записи метаданных, включая `removed` и `unknown`. Состояние видно в свёрнутой карточке. Счётчик не означает число активных обработчиков на всей странице: ранние регистрации и недоступные контексты могут отсутствовать в снимке, а объём данных ограничен.

## Карточка записи

Нажимаем карточку или переводим фокус на её заголовок и нажимаем Enter либо пробел. Внутри показаны цель, путь, источник регистрации, расположение скрипта, frame, document, тип контекста и жизненный цикл. Доступные параметры `capture`, `passive` и `once` сохраняют значения `true` и `false`; отсутствие значения показано как «Неизвестно».

Если есть сведения о навигации, причины ограничений или дополнительные параметры источника, карточка показывает их как текст. Значения не превращаются в ссылки, HTML или сетевые запросы. Расширение не собирает код callback, значения полей и содержимое clipboard.

При обновлении данных того же документа запрос и раскрытые карточки сохраняются. Смена вкладки, сайта или главного документа сбрасывает локальное состояние панели; отзыв доступа, перезагрузка и ошибка скрывают результаты. Отфильтрованные карточки удаляются из списка, поэтому при возврате в выдачу они свёрнуты.

## Покрытие сбора

Над результатами popup объясняет каждую известную причину неполного покрытия. Причины независимы и могут появляться одновременно.

| Причина                | Что означает                                                                                        | Действие                                                                                             |
| ---------------------- | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `FRAME_PARTIAL`        | Покрытие фреймов неполное: встречен другой адрес, неподтверждённый origin или недоступный контекст. | Для фрейма другого сайта открываем его отдельно, выдаём доступ и перезагружаем исходную вкладку.     |
| `RECORD_LIMIT_REACHED` | Потеряны записи из-за лимита буфера вкладки или реестра детектора.                                  | Учитываем, что поиск работает только по сохранённым записям; для нового сбора перезагружаем вкладку. |

Буфер хранит до 200 последних добавленных записей. Обновление существующей записи сохраняет её позицию и само по себе не означает переполнение. Ограничение появляется после фактической потери данных и сохраняется до нового сбора главного документа. Реестр `addEventListener` и реестр property/inline slots ограничены 2000 записями каждый; новые регистрации сверх лимита имеют `unknown`, а ранее учтённые продолжают обновляться.

Кнопка «Перезагрузить вкладку» доступна при ограниченном покрытии. Она скрывает текущие результаты на время запуска нового сбора. Если вкладка уже перешла на другой сайт, действие отменяется и popup обновляет состояние. Перезагрузка не выдаёт разрешений другим сайтам.

Если background вернул `limited` без подробностей, popup показывает общее пояснение. Даже при `ready` сохраняется предупреждение о регистрациях до установки hook.

Property handler и inline-атрибут — отдельные наблюдаемые поверхности с `SURFACE_UNVERIFIED`. Их наличие не доказывает, что браузер исполняет два callback: обе поверхности могут относиться к одному нативному слоту. Замена, удаление и повторное добавление обновляют запись с прежним ID.

## Пустые результаты

| Сообщение                        | Значение                                                                                                |
| -------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Обработчики событий не найдены.  | Готовый сборщик вернул пустой снимок. Это не гарантирует отсутствие ранних или недоступных регистраций. |
| Пока нет данных об обработчиках. | При ограниченном покрытии снимок пока пуст; отсутствие обработчиков не подтверждено.                    |
| По запросу ничего не найдено.    | В снимке есть записи, но фильтр не нашёл совпадений. Можно сбросить поиск.                              |
