# Listener Lens

## TL;DR

Listener Lens показывает зарегистрированные обработчики DOM-событий в Chrome и Firefox. Доступ включаем отдельно для выбранного сайта; после разрешения перезагружаем вкладку. Значения полей, содержимое clipboard и код callback не собираем.

## Features

- Выдача и отзыв доступа к выбранному сайту из popup.
- Динамический content script на `document_start` и best-effort listener hook.
- Метаданные `addEventListener`, property и inline handlers; описания событий и подсветка доступных DOM-целей.
- Поиск по метаданным и фильтры по состоянию, источнику и фрейму; группы и карточки записей.
- Разделение записей по вкладке, frame и документу; восстановление после перезапуска background и возврата из BFCache.
- Пояснения ограничений фреймов и лимита записей с перезапуском сбора.
- Локальный JSON-экспорт и сравнение двух снимков в пределах текущего документа.

## Installation

```bash
pnpm install --frozen-lockfile
pnpm playwright:install
pnpm dev
```

## Usage

```bash
pnpm dev
```

Открываем HTTP/HTTPS-страницу и popup, нажимаем «Разрешить для этого сайта», подтверждаем запрос браузера и нажимаем «Перезагрузить вкладку». Чтобы прекратить сбор, выбираем «Отозвать доступ».

Для сохранения результатов нажимаем «Экспорт всего снимка» или задаём поиск и фильтры, затем выбираем «Экспорт выборки». Браузер скачивает JSON локально.

Чтобы увидеть изменения регистраций, выбираем «Запомнить снимок», выполняем действия на странице и снова открываем popup. Базовый снимок сохраняется между открытиями popup. Навигация, отзыв доступа или перезапуск background сбрасывают его.

В раскрытой карточке нажимаем «Показать элемент», чтобы прокрутить страницу к цели и временно подсветить её. Для удалённой или недоступной цели popup объясняет отказ.

## Architecture / Stack

Используем `WXT`, `React`, `TypeScript`, Manifest V3 и `webextension-polyfill`. Background согласовывает выданные host permissions с динамическими регистрациями content script. Bridge в контексте страницы фиксирует metadata; content script передаёт их в background после проверки доступа и сессии документа. Popup получает подтверждённый снимок состояния.

## Ограничения

Hook работает best effort: регистрации до его установки могут быть невидимы. Защищённые страницы браузера недоступны; междоменные iframe требуют собственного разрешения. Живой сборщик восстанавливает ограниченный снимок автоматически. Если перезапуск браузера или обновление расширения уничтожили content script, нужна перезагрузка страницы.

`active` означает наблюдённую регистрацию без известного удаления. Для `once` показываем `unknown`: срабатывания не отслеживаем. Явное удаление или наблюдённая отмена текущего signal дают `removed`; сведения об отмене могут быть неполными. Подробности — в [панели результатов](docs/popup-results.md#состояния-регистрации).
